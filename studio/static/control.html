    Send yourself a text

    Shows as an in-game phone notification.

    1. Install into GTA V

    Needs Script Hook V in the game folder. Story mode only.

      2. Make your call page reachable (Cloudflare Tunnel)

      Only the call page (port 8771) goes online. Never tunnel this control panel (8770).

      1. Install cloudflared: winget install Cloudflare.cloudflared
      2. Quick test (random address, changes every run):
        cloudflared tunnel --url http://127.0.0.1:8771
      3. Permanent address on your own domain:
        cloudflared tunnel login
cloudflared tunnel create phonelink
cloudflared tunnel route dns phonelink call.yourdomain.com
cloudflared tunnel run --url http://127.0.0.1:8771 phonelink
      4. Paste the public address below and save.
      Relay server (TURN) — only if some friends can't connect

      Most calls connect directly. On strict networks (some mobile carriers, offices) a TURN relay is needed — e.g. Cloudflare Realtime TURN.

      Plugin connection

      Must match PhoneLink.ini in the game folder.

      Tips

      • Use headphones — otherwise your mic picks up the game and your friend's voice (echo).
      • Answer with Y, decline or hang up with N (changeable in PhoneLink.ini).
      • While you're on a call, other friends see Busy; when the game is closed they see Not in game.

      Studio log

      For game-side problems also check PhoneLink.log in the game folder.
